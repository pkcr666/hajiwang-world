# 新手村抢商店实现方案

## 概述

在「哈基汪世界」新手村（starterVillage）的诡异行商节点新增「抢商店」功能：

1. 点击「抢商店」进入 BOSS 战（袁绍）；成功击败后当前货摊所有商品价格变为 0，可免费购买。
2. 本局抢过一次后（`robbedShop`），后续进入任何诡异行商节点都显示空摊（里面什么都不会有）。
3. 新手村商店的商人头像改为袁绍图像（与 BOSS 共用同一文生图资源）。
4. BOSS 袁绍：HP1200 / 攻120 / 防120 / 法抗60 / 速度1-9。
5. 奇数回合（含第 1 回合）开始前弹出抉择弹窗，三选一：
   - 膜拜袁绍：其防御与法抗变为 50%，持续两回合（worship buff 2 层，回合末衰减）。
   - 勾引袁绍：魅力判定（队长魅力 + 1D50 ≥ 60），成功造成 300 点真实伤害（已按用户要求改为固定 300，原公式 `(魅力+1D50)*5` 作废）。
   - 拿钱砸死：输入哈哈币数量（自由输入），本回合袁绍攻击力减少 `floor(数量/100)`，回合末恢复；扣减币池。

## 现状分析（已确认的关键代码）

- 抢商店入口：`src/pages/RunMerchant.tsx` L225 已有 disabled 按钮 `<button className="btn" disabled title="后续版本开放">抢商店</button>`；商人头像为 L221 `🧙` emoji。
- 商店结构：`NodeState = { kind:'merchant'; shop: MerchantShop; refreshed: boolean; haggle? }`（types.ts L637）；`RunState`（L641-670）有 nodeStates/coins/robbedShop 待加字段。
- 战斗引擎：`advance`（battle.ts L864-994）是唯一回合推进入口：回合末结算（L883-932）→ 新回合初效果 → `ns.turn += 1` → `rollOrder` → `cursor = 0` → 定位存活单位。奇数回合抉择在此插入暂停点（仿 `pendingReaction` 模式）。
- 战斗暂停模式参考：`resolveReaction`（battle.ts L826-861）+ Battle.tsx 弹窗（L431-455）+ 回合驱动 effect（L115-133）。
- BUFF：`addBuff`/`buffValue`/`tickBuffsEndOfTurn`（回合末层数-1）；`effDefBuffed`（buffs.ts L131-134）算有效防御；`calcDamage` 法术分支（damage.ts L68）用 `target.stats.mres`。
- 六维判定：`statCheck(statValue, threshold, rng)`（events.ts L11-18）= 1D50 + 属性 ≥ 阈值。
- 怪物数据：`src/data/monsters.json`（单行 JSON 数组），`src/data/monsters.ts` 的 `MONSTER_SEED_VERSION = 5`，存档以 `customMonsters` 为唯一事实源（content.ts L11），loadSave 在版本不符时整体重置播种（storage.ts L79-90）。
- 图像：`src/assets/config.ts` `MONSTER_IMAGES`（文生图 URL）；`Sprite` 组件渲染图像。
- runBattle view：`App.tsx` L279-351，`stage` 缺失会跳回地图（L289-305），抢商店战斗必须绕过该限制。
- `finishRunBattle`（App.tsx L108-179）：win 走奖励结算，lose 走时光之末/团灭结算。

### 7. `src/engine/battle.ts` — 抉择引擎
- 新增常量：`export const ROB_SEDUCE_THRESHOLD = 60;`、`export const ROB_SEDUCE_DAMAGE = 300;`
- `advance` 两处改动：
  1. 回合末结算循环内（`tickBuffsEndOfTurn(u)` 之后，L931 附近）追加：`if (u.atkCut) { u.stats.atk += u.atkCut; u.atkCut = 0; }`（砸钱减攻仅本回合有效）。
  2. 新回合 rollOrder 之后（L974 `addLog(ns, { t: 'roll', turn: ns.turn }); cursor = 0;` 之后、while 循环之前）追加：
     ```ts
     // 抢商店BOSS战：奇数回合开始前暂停，等待玩家抉择
     if (ns.choiceMode && ns.turn % 2 === 1) {
       ns.pendingChoice = { turn: ns.turn };
       ns.cursor = 0;
       return ns;
     }
     ```
- 新增导出函数（仿 `resolveReaction` 模式，顶部 import `statCheck` from './events'）：
  ```ts
  export type RobChoice =
    | { kind: 'worship' }
    | { kind: 'seduce'; cha: number }
    | { kind: 'coins'; amount: number };

  export function resolveRobChoice(s: BattleState, choice: RobChoice, rng: Rng = mathRng): { state: BattleState; events: LogEntry[] }
  ```
  逻辑：clone → 定位存活袁绍（`e.monsterId === 'yuanShao'`，兜底取第一个存活敌人）→ 按 choice 处理并写 log：
  - `worship`：`addBuff(target, 'worship', 2, 1)`，记 buff log。
  - `seduce`：`statCheck(choice.cha, ROB_SEDUCE_THRESHOLD, rng)`，通过则 `damageFlat(ns, target.uid, ROB_SEDUCE_DAMAGE, 'true')` + 成功 log；失败仅 log「不为所动」（无惩罚）。
  - `coins`：`cut = Math.floor(choice.amount / 100)`；`target.atkCut = cut; target.stats.atk = Math.max(0, target.stats.atk - cut);` + log。
  - 清 `ns.pendingChoice = undefined`，返回 `{ state, events: ns.log.slice(start) }`。

- 新增处理函数：
  ```ts
  const doRobChoice = (choice: RobChoice) => {
    if (choice.kind === 'coins') {
      const amount = Math.floor(Number(coinInput));
      if (!Number.isFinite(amount) || amount <= 0) return;
      const coins = save.activeRun?.coins ?? 0;
      if (amount > coins) return; // 不能超过现有币池
      runMode?.onSpendCoins?.(amount);
    }
    const r = resolveRobChoice(battle, choice, mathRng);
    if (r.state === battle) return;
    pushFloats(r.events);
    setBattle(r.state);
    setRobCoinsAsk(false); setCoinInput('');
  ```

## 假设与决策（已与用户确认）

1. 「勾引」规则改为：魅力判定（队长魅力 + 1D50 ≥ 60），成功造成 **300 点真实伤害**；失败无惩罚。原公式 `(魅力+1D50)*5` 不采用。
2. 「拿钱砸死」金额为自由输入；扣减当前币池，不超过持有数量；减攻 `floor(数量/100)` 仅本回合有效（回合末恢复）。
3. 抉择出现在**每个奇数回合开始前（含第 1 回合）**，玩家必须三选一后才能行动（弹窗不可关闭）。
4. BOSS 称呼统一「袁绍」（非「方源」）；商人头像与 BOSS 图像共用袁绍文生图。
5. 抢商店按钮仅在新手村（starterVillage）行商节点显示；其他副本行商不显示。
6. 抢店成功后：当前货摊商品价格全 0 可免费购买（砍价/刷新禁用）；本局再进其他行商节点一律空摊。
7. 抢商店战斗失败按普通战斗失败处理（时光之末可触发；团灭则正常结算）。
8. 膜拜效果「两回合」= worship buff 2 层，回合末层数-1，覆盖抉择回合及其后一回合。
